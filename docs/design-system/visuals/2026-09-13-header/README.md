# 변경 후 공통 헤더 — 2026-09-13

이번 전체 RESERVE 워드마크·검색 아이콘 전환 **후** 로컬 브라우저 확인 기록이다.
변경 전 디자인 소스를 동결한 [기준선 스냅샷](../../snapshots/2026-09-13-baseline/README.md)과는 다르다.

## 브라우저 캡처

- [PC 헤더](desktop.png): CSS 뷰포트 1440×900, 상단 1440×150 native PNG 캡처.
- [모바일 헤더](mobile.png): CSS 뷰포트 390×844, 상단 390×150 native PNG 캡처.
- `/stores`의 공개 손님 화면, 이미 설정된 다크 테마에서 확인했다. 테마/브라우저 줌/계정 설정은 변경하지 않았다.
- PNG는 캡처 결과 그대로 보관했다. 로고 이미지를 새로 제작하거나 캡처를 합성·편집한 것은 아니다.

## 직접 확인한 변경 범위

| 화면 | 헤더 | 워드마크 | 검색 액션 | 뒤로가기 | 가로 넘침 |
|---|---|---|---|---|---|
| PC 1440px 공개 목록 | 64px | RESERVE / 22px | 44×44px | 없음 | 없음 |
| 모바일 390px 공개 목록 | 64px | RESERVE / 22px | 44×44px | 없음 | 없음 |
| 모바일 320px 분야 결과 | 64px | RESERVE / 22px | 44×44px | 표시 | 없음 |
| PC 1440px 분야 결과 | 64px | RESERVE / 22px | 44×44px | 숨김 | 없음 |

표는 화면에 렌더된 DOM의 치수/computed style을 읽은 결과다. 사진의 픽셀만으로 CSS 치수를 추정하지 않았다.
모바일 목록에서 검색 아이콘으로 `/search`에 진입하고 입력 포커스·전용 화면·취소 시 목록 복귀를 확인했다.
임시 뷰포트 오버라이드는 확인 후 해제했다.

헤더 4개 집중 테스트와 해당 JSX의 ESLint 검사를 실행했다. 로그인 사용자/역할별 메뉴,
전체 페이지·전체 뷰포트 조합·운영 배포 상태를 확인한 기록은 아니다. 전체 테스트/프로덕션 빌드는 실행하지 않았다.
