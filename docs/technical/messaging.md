# 통합 메시지

고객지원 문의와 가게 문의를 하나의 메시지 화면에서 이용해요.

## 대화 종류

| 종류 | 참여자 |
|---|---|
| 고객지원 | 회원과 관리자 |
| 가게 문의 | 회원과 해당 가게 운영자 |

가게의 삭제·정지·계정 권한과 대화 참여 여부를 서버에서 확인해요. 자기 가게에 새 문의를 만들 수 없어요.

## 메시지 처리

- 최근 메시지부터 읽고 이전 대화는 커서로 나눠 불러와요.
- 전송 요청의 식별자로 중복 메시지를 구분해요.
- 메시지와 읽지 않은 수를 함께 갱신해요.
- 화면이 다시 보이거나 연결이 복구되면 서버 기록과 다시 맞춰요.
- 전송 실패 시 작성 중인 내용을 복구할 수 있게 해요.

## 화면

PC에서는 패널, 모바일에서는 전체 화면을 사용해요. 뒤로가기·닫기·키보드 포커스와 모션 줄이기 설정을 지원해요.

대화 숨김은 내 목록에만 적용해요. 전송 취소, 상대 차단, 신고는 각각 별도 기능이며 참여자의 권한과 처리 조건을 확인해요.

## 사진과 보관

사진은 암호화해 저장하고 참여 권한을 확인한 API로 제공해요. 공개 이미지 CDN 주소로 전달하지 않아요.

원문과 신고 증거의 보존은 [데이터 보관과 삭제](data-lifecycle.md), 설정과 전송 취소는 [채팅 관리](chat-controls.md), 사진 키는 [채팅 사진](chat-images.md)을 보세요.

## 코드 위치

화면은 frontend/src/components/chat, 서버는 backend의 chat 영역에 있어요.
