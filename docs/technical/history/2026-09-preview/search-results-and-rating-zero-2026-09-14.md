# 검색 결과 헤더와 0리뷰 평점 통일

2026-09-14 `local-preview-all-changes` 로컬 구현·검증. 커밋·dev 통합·운영 배포 완료를 뜻하지 않는다.

## 검색 구성

- 추천·반영한 흐름은 ‘검색 결과에서도 검색어 확인 → 필드를 누르면 기존 `/search`에서 수정 → 제출 후 새 결과’다. 두 화면에 별도 편집·검색 구현을 중복하지 않는다.
- 검색어가 있는 `/stores`의 공통 헤더에 검색 아이콘·현재 검색어를 담은 pill 링크를 둔다. 입력처럼 보이는 면이지만 실제 편집 가능한 input은 아니며, 접근성 라벨은 ‘검색어 수정: …’이다. 누르면 `/search?keyword=…`로 검색어를 복원한다.
- 현재 검색어는 React 텍스트로 렌더하고 링크는 encodeURIComponent로 인코딩한다. 긴 검색어는 한 줄 말줄임과 전체 title을 사용한다.
- 필드는 높이 44px·16px 글꼴·최대 560px의 유동 폭이며 기존 테마·중립 포커스 토큰을 사용한다. 별도 실행 텍스트나 중복 검색 아이콘을 더하지 않는다.
- 768px 미만의 검색어 결과 헤더에서만 RESERVE를 R로 줄인다. 모바일 뒤로가기·계정 메뉴의 44px 영역을 유지한다. 검색어가 없는 탐색·홈·분야 결과·상세·계정 화면과 모든 PC 화면은 전체 워드마크를 유지한다.
- 기존 `/search` 왼쪽 돋보기는 장식 span에서 네이티브 `type=submit` 버튼으로 바꿨다. 아이콘 클릭·Enter·모바일 검색 키가 같은 form 제출을 사용한다. 빈 입력은 제출하지 않고 한글 조합을 확정하는 Enter/229는 검색을 실행하지 않는다.
- 검색어 지우기는 입력만 비우고 포커스를 복원한다. 헤더에서 들어와 취소하면 기존 결과의 검색·분야·정렬·보기·페이지로 돌아간다. 직접 연 검색 화면의 취소/Escape는 기존 홈 복귀 정책이다. 새 검색 제출은 기존 정책처럼 새 검색어의 첫 결과로 이동한다.
- 입력 변경만으로 검색 API를 호출하지 않으며 기존 검색 API·권한·목록 query key를 바꾸지 않았다.

## 평점 표시

- 가게 요약의 0리뷰 문구를 별 아이콘·`0.0 (0)`으로 통일했다. 대상은 `StoreCard`(탐색/관심/혜택 재사용 포함), `StoreListRow`, 홈 추천, 가게 상세의 공유 `StoreIdentity`, 내 가게, 관리자 가게 표다.
- 순수 유틸 `normalizeStoreRating`에서 정상 숫자/숫자 문자열을 정규화한다. 리뷰 수가 없거나 0/잘못된 값이면 점수·리뷰 수 모두 0이다. 정상 양수 리뷰 수와 0~5 점수는 유지한다.
- 알려진 리뷰 수가 양수인데 점수만 잘못됐으면 NaN 대신 0.0을 표시하되 실제 리뷰 수는 보존한다. 화면에서는 소수 한 자리와 한국어 천 단위 괄호 리뷰 수를 표시한다.
- 기존 카드·배지·관심 가게·상세 문의·표 구조를 유지했다. 관리자 표 평점 셀과 스켈레톤 칸만 70→140px로 맞췄다. 사용하지 않게 된 목록/홈의 no-reviews CSS는 제거했다.
- 개별 리뷰·리뷰 작성·리뷰 본문이 없는 빈 목록 안내는 이 변경 대상이 아니다. 실제 가게/리뷰 데이터를 생성하거나 평점·리뷰 수·정렬 정책을 변경하지 않았다.
