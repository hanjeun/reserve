# 사장님 가이드

가게를 등록하고 예약·웨이팅·광고를 관리하는 방법이에요.

## 사업자 인증

마이페이지의 사업자 메뉴에서 상호·사업자 등록번호·등록증을 제출해요. 관리자가 승인하면 가게 관리 기능을 이용할 수 있어요.

## 가게 등록

내 가게에서 새 가게 등록을 선택하고 안내 순서대로 입력해요.

| 영역 | 내용 |
|---|---|
| 기본 설정 | 업종·접수 방식·예약 방식 |
| 접수와 일정 | 웨이팅·영업 일정·예약 접수 규칙 |
| 예약금 | 금액·결제 시점·취소와 환불 조건 |
| 소개와 사진 | 가게 정보·대표 사진·상세 사진 |

예약은 시간대·회차·날짜 단위 중 가게에 맞는 방식을 사용해요. 대표 사진은 한 장, 상세 사진은 최대 다섯 장이며 새 이미지 합계는 8MB까지예요.

예약금이 없으면 결제·환불 항목을 필수로 입력하지 않아요. 유료 예약은 신청할 때 결제할지, 나중 결제를 허용할지 정해요. 양수 결제 제한 시간이 있는 신청 시 결제 예약만 미결제 자동 취소를 적용해요.

입력은 같은 브라우저에 임시저장돼요. 요약과 상세 미리보기를 확인한 뒤 등록을 완료해요.

## 예약 관리

사업자 패널에서 예약을 검색하고 상태를 바꿔요.

| 동작 | 의미 |
|---|---|
| 승인·거절 | 예약 신청 처리 |
| 완료 | 서비스 이용 완료 |
| 노쇼 | 방문하지 않은 예약 처리 |

예약 접수·자동 승인·예약금 설정은 가게의 운영 방식에 맞춰 관리해요.

## QR 체크인

사업자 패널의 QR 스캔에서 승인된 예약이나 호출된 웨이팅 QR을 확인해요. 예약 체크인은 방문 시각을 기록하며, 서비스 완료는 예약 목록에서 따로 처리해요.

## 웨이팅과 문의

가게에서 제공할 접수 방식을 설정하고 사업자 패널에서 명단·호출·입장·취소를 관리해요. 가게 문의는 메시지 받은편지함에서 답장해요.

## 광고와 통계

광고 메뉴에서 종류·기간·금액과 배너 내용을 확인한 뒤 결제해요. 신청·결제·노출 상태는 광고 목록에서 확인해요.

통계는 예약 현황과 환불을 뺀 예약금 순결제액을 보여줘요. 차트 아래 데이터 표에서도 같은 수치를 확인할 수 있어요.

## 수정과 영업 종료

내 가게의 수정에서 고칠 영역을 선택하고 미리보기를 확인한 뒤 저장해요.

가게를 삭제하려면 남은 예약·광고·결제·환불을 먼저 처리해야 해요. 알림과 사업자 자격은 마이페이지에서 관리해요.
