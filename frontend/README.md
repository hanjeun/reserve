# RESERVE Frontend

React 19 + Vite 7 기반 식당 예약 시스템 프론트엔드

## 시작하기

```bash
npm install
npm run dev
```

## 빌드

```bash
npm run build
npm run preview
```

## 환경변수 (.env)

```
VITE_API_BASE_URL=http://localhost:8080
VITE_PORTONE_IMP_CODE=imp_xxxxxxxx
VITE_KAKAO_CHANNEL_KEY=_xxxxxxx
```

## 프로젝트 구조

`src/STRUCTURE.md` 참고
