# 데이터 보관과 삭제

화면에서 숨기는 것, 복구 가능한 삭제, 원본을 영구 삭제하는 것은 서로 다른 작업이에요.

## 탈퇴와 가게 영업 종료

남은 예약·결제·환불이 있으면 먼저 처리해야 해요. 탈퇴나 영업 종료만으로 거래 기록과 신고 증거를 함께 지우지 않아요.

탈퇴하면 개인정보와 계정 연결을 정리하고 이전 인증을 사용할 수 없게 해요. 외부 서비스 연결 해제와 파일 삭제는 별도 작업 기록을 남겨 처리해요.

## 외부 파일과 계정 연결

데이터 변경과 같은 트랜잭션에 외부 작업을 기록해요. 이 저장된 재시도 목록을 outbox라고 해요.

- 파일은 사용 중인 다른 참조가 없는지 확인한 뒤 지워요.
- 외부 서비스 호출이 실패하면 정해진 간격으로 재시도해요.
- 결과가 불명확한 작업은 성공으로 처리하지 않아요.
- 완료한 작업의 토큰·파일 경로 등 불필요한 정보는 제거해요.

## 휴지통과 감사 기록

| 대상 | 기본 보관 |
|---|---|
| 휴지통 항목 | 30일 |
| 복구·삭제·제재 등 일반 감사 기록 | 90일 |

거래나 다른 보존 사유가 연결된 자료는 자동 영구 삭제에서 제외해요.

## 예약 개인정보와 거래 증거

이용 종료 30일 후 가게·일반 관리자 예약 조회에서 이름·이메일·요청사항과 자유 입력 사유를 가려요. 개인정보 검색과 과거 예약 휴지통의 원문 사본도 같은 접근 제한을 따라요. 본인 예약 조회는 유지해요.

거래·이용 종료의 가장 늦은 기준부터 5년 동안 별도 권한의 거래 증거를 보관하고, 진행 중인 사건은 파기를 보류해요. 해제한 분쟁 기록의 3년이 더 늦으면 그 기간을 지켜요. 추가 인증을 마친 관리자가 목적과 개인정보 없는 사건 참조 번호로 보류·해제를 관리해요.

예약 전용 작업은 종료 상태·금전 확인·미처리 웹훅·사건 보류를 확인한 뒤 관련 예약·동의·결제 증거를 같은 트랜잭션에서 파기해요. 표와 제한 계정·독립 복원·호환 복구를 검증하고 승인하기 전까지 보유기간 활성화와 자동 파기는 비활성으로 유지해요. 일반 휴지통의 30일 기한으로 예약 증거를 물리 삭제하지 않아요.

## 채팅과 신고

일반 메시지와 사진은 전송일부터 90일 보관해요. 기존 자료의 기간 정리는 실제 고지와 유예기간을 확인해 시작해요.

처리되지 않은 신고·분쟁·보존 요청이 있으면 관련 원문과 증거를 유지해요. 신고·거래 증거는 분류에 맞는 보관기간을 적용하고, 일반 메시지의 삭제 기한으로 함께 지우지 않아요.

## 웨이팅

고객·직원 접수는 각각 고지한 정책을 사용해요. 진행 중인 접수를 날짜만 바뀌었다고 지우지 않으며, 종료한 접수의 표시명과 기록은 정해진 기간에 정리해요.
