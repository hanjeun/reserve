# 손님 가이드

RESERVE에서 가게를 찾고 예약하는 방법을 안내합니다.

---

## 회원가입

1. 우측 상단 **로그인** 버튼 클릭
2. **회원가입** 선택
3. 이메일 입력 후 **인증코드 전송** 클릭
4. 받은 이메일의 인증코드 입력
5. 이름 · 비밀번호 입력 후 가입 완료

> Google, Naver, Kakao 계정으로도 바로 가입할 수 있습니다.

---

## 가게 찾기

1. **가게 둘러보기** 버튼 또는 상단 메뉴에서 가게 목록 이동
2. 검색창에 가게 이름 · 키워드 입력
3. 정렬 기준 선택 (평점순 / 최신순 / 리뷰순)
4. 원하는 가게 카드 클릭

---

## 예약하기

1. 가게 상세 페이지에서 **예약하기** 클릭
2. 날짜 · 시간 · 인원 선택
3. 요청 사항 입력 (선택)
4. **예약 신청** 버튼 클릭

> 예약금이 있는 가게는 예약 후 결제 화면으로 이동합니다.

---

## 예약금 결제 (카카오페이)

1. 예약 신청 후 결제 화면에서 **카카오페이로 결제** 클릭
2. 카카오페이 앱에서 결제 승인
3. 결제 완료 후 예약 확정

> 결제하지 않으면 일정 시간 후 예약이 자동 취소됩니다.

---

## 예약 확인 · 취소

1. 우측 상단 프로필 → **내 예약 확인**
2. 예약 목록에서 상태 확인
   - 대기중 · 확정 · 완료 · 취소
3. 취소하려면 해당 예약의 **취소** 버튼 클릭

> 환불 정책은 가게마다 다를 수 있습니다.

---

## 리뷰 작성

1. 완료된 예약의 **리뷰 작성** 버튼 클릭
2. 별점 · 내용 입력 후 등록

---

## 즐겨찾기

- 가게 카드 또는 상세 페이지의 **하트 아이콘** 클릭
- 프로필 → **즐겨찾기**에서 모아보기

---

## 마이페이지

프로필 → **마이페이지**에서 아래 정보를 수정할 수 있습니다.

- 이름 변경
- 비밀번호 변경 (이메일 회원만)
- 프로필 사진 변경
- 예약 알림 이메일 수신 설정
- 사업자 전환 신청
