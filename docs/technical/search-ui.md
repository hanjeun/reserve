# 검색 전용 화면과 헤더

공통 헤더, `/search` 전용 검색 화면, 가게 목록의 배치와 동작 규칙이에요.

## 공통 헤더

- PC·모바일 모두 Pretendard·22px·850 굵기·-0.8px 자간의 전체 RESERVE 워드마크를 써요. 로고는 홈으로 이동해요.
- 오른쪽은 검색 아이콘 → 둥근 프로필 사진 순서예요. 검색 아이콘은 공용 `/search` 라우트로 가는 링크이고, 헤더에는 입력 모양 검색창을 두지 않아요.
- 검색어가 있는 `/stores` 결과에서는 아이콘 대신 현재 검색어를 보여 주는 검색 진입 필드를 둬요.
  - PC: [로고][검색창][계정] 3칸 격자로, 필드를 화면 가운데·최대 560px(검색 화면 입력칸과 같은 자리)에 두고 워드마크를 유지해요.
  - 768px 미만: 로고를 숨기고 뒤로가기와 검색어 필드만 둬요.
- 탐색 루트가 아닌 분야·검색 결과 목록, 상세, 계정 화면에는 **PC와 모바일 모두** 공통 뒤로가기가 있어요. 기존 `useGoBack`으로 이전 화면, 앱 히스토리가 없으면 목록/홈으로 가요. 상세 본문에는 중복 뒤로가기를 두지 않아요.
- 높이는 모든 페이지에서 64px이고 반응형 여백도 같아요. 검색 아이콘은 44×44px, 로고·프로필·뒤로가기도 44px 높이 동작 영역이에요.
- hover는 중립 opacity, 키보드 포커스는 공통 CSS의 링이에요. 헤더·홈의 로고/텍스트 scale 눌림은 없애고 사진/3D 효과는 남겼어요. scroll-snap 메인 배너는 축소하지 않는 별도 패턴이에요.
- 비로그인 `로그인`·`시작하기`는 767px 이하에서 4px 컨테이너 간격과 13px 안쪽 여백을 유지해요. 900px 이상에서는 CTA가 붙어 보이지 않게 두 버튼 사이만 12px로 둬요.
- 로그인 전 프로필 메뉴에는 로그인·회원가입·탐색 링크가 있어요. 보호된 링크는 PrivateRoute를 거쳐요.
- 예약/관심/알림/메뉴 아이콘 추가는 계획 후보일 뿐이에요.

## 탐색 탭

- `홈 · 탐색 · 혜택 · 웨이팅 · 피드` 탭은 공통 레이아웃에 한 번 두고, PC·모바일 모두 44px 높이예요.
- `/stores` 전체 탐색(정렬 포함)은 탭을 유지하고, 분야/검색 결과는 하위 화면으로 보고 탭을 숨겨요.
- 혜택은 공개 홍보글을 읽는 소식·혜택 안내와 `/benefits/:id` 상세예요. 쿠폰 발급/사용 모델은 없고, 기획전 전환은 [디자인 전환 계획 §11](history/2026-09-preview/design-evolution-plan-2026-09-13.md)에 있어요.
- 웨이팅·피드는 준비 화면이에요. 원격 대기 접수·게시 기능은 없어요.
- 고정 하단 페이지 메뉴와 높이 보정 공백은 없어요(프로필 메뉴와 중복). 법적 고지·문의 푸터는 유지해요.

## 검색 화면

- 고정 480px 앱 프레임을 쓰지 않아요. 본문은 최대 960px, 여백은 모바일 20px(아주 좁으면 16px)·태블릿/PC 24px이에요.
- 전역 헤더·탭·푸터를 숨기고 자체 입력·취소 행(64px 고정)을 써요.
- PC 입력은 공통 헤더와 같은 최대 560px이고, [빈 칸][입력칸][취소] 격자로 입력칸을 화면 가운데에 둬요.
- 입력은 44px 높이/100px 반경 pill이에요. 글꼴 16px, 지우기·취소 동작 영역 44px, 포커스는 파란 링 대신 중립색 테두리예요.
- 분야 선택은 모바일 3열/2행, 768px 이상 6열/1행이에요. 아이콘은 물체별 광학 크기를 유지하고 넓은 화면에서 과하게 키우지 않아요.
- 홈·검색 분야 아이콘은 `constants/discovery.js`의 이미지/광학 크기 정보를 공유해요.

## 검색 동작

- 열면 입력에 포커스가 가요. 왼쪽 아이콘은 `type=submit` 버튼이고, Enter·모바일 키보드 검색과 같은 form 제출을 써요.
- 앞뒤 공백을 뺀 검색어를 `/stores?keyword=…` 결과로 넘겨요. 빈 값은 제출하지 않고, 한글 조합 확정 Enter로는 검색하지 않아요.
- 입력 변경만으로 검색 API를 부르지 않아요. 별도 백엔드·검색 서버·DB 테이블은 없어요.
- 지우기는 입력만 비우고 포커스를 유지해요. 취소나 Escape는 헤더로 들어왔으면 이전 화면, 직접 접근했으면 홈으로 가요.
- 빠른 검색 문구는 안내용 예시예요. 인기 순위·현재 위치·개인화 추천으로 표현하지 않아요.
- 최근 검색어 저장, 서버 자동완성, 인기 검색 집계는 없어요. 입력 내용을 localStorage나 DB에 저장하지 않아요. 인기 검색어는 집계·갱신 시각·공개/보존 기준이 생기기 전까지 도입하지 않아요.
- `/search`는 `useRouteSeo`의 비색인 기본 정책을 따라요. 서버 X-Robots-Tag 정책은 배포 준비 때 따로 맞춰요.

## 검색 결과와 가게 목록

- 목록 본문에는 검색 입력·검색 버튼이 없어요. 결과 헤더 필드는 현재 검색어를 한 줄로 보여 주고, 누르면 `/search?keyword=…`로 입력을 복원해요. 편집·제출은 검색 화면에서만 해요. 수정을 취소하면 기존 결과의 필터·보기·페이지로 돌아가요.
- 결과 헤더 필드는 링크로 노출하고, ‘검색어 수정: …’ 라벨·말줄임·전체 검색어 title을 줘요. 44px 높이·16px 글꼴·최대 560px 유동 폭이에요.
- 목록은 큰 제목·소개 없이 시작해요. 가게 수는 왼쪽, 분야·정렬 메뉴는 오른쪽에 나란히 둬요. 페이지 제목은 화면 낭독기용 `h1`으로만 남겨요.
- 필터 왼쪽 아이콘으로 사진형(`view=cards`, 원본 비율)과 목록형(`view=list`, 정사각 사진 + 정보)을 전환해요. 아이콘은 다음에 바뀔 보기 모양이에요. 보기만 바꾸면 페이지·필터를 유지하고 목록 API를 다시 부르지 않아요. 스켈레톤도 선택한 보기에 맞추고, 조회 중에는 아이콘을 잠가요.
- 결과는 서버에서 12건씩 받고, 하단 AntD 페이지네이션을 PC·모바일 공통으로 써요. URL의 검색·분야·정렬은 유지하고, 조건이 바뀌면 첫 페이지로 가요. 무한 스크롤은 없어요.

## 접근성과 테마

- 검색 입력에 명시적 라벨과 `role=search`, 지우기 버튼에 라벨을 둬요.
- 헤더·탐색 탭·검색 화면의 링크/버튼은 중립색 2px 키보드 포커스 링을 써요. 검색 결과 링크와 메뉴의 인증 경계를 우회하지 않아요.
- 분야·정렬 `FilterMenu`는 입력 없는 투명 텍스트 스타일이에요. 보이는 면 32px, 동작 영역 44px, 옵션 메뉴는 최소 128px 폭·4px 여백·10px 반경, 항목은 모바일 40px·PC 36px 최소 높이예요. 마우스·터치에는 링/축소가 없고 키보드 포커스에만 링을 둬요. 거리순의 위치 요청 동작은 그대로예요.
- 로고의 홈 smooth scroll은 모션 감소 설정을 따라요.
- 시스템 테마가 바뀌면 `useTheme`가 새 snapshot을 알려 CSS 화면과 AntD 메뉴 algorithm이 함께 바뀌어요.

화면 실측 수치는 [design-measurements-2026-09-13.md](history/2026-09-preview/design-measurements-2026-09-13.md)에 있어요.

## 페이지 전환

- 검색 화면은 열 때 본문이 올라오고, 취소·Esc로 닫을 때 내려가요. 검색 실행·빠른 검색은 결과를 바로 스켈레톤으로 채우고, 옆으로 밀리는 전환을 걸지 않아요. 검색은 화면 이동이 아니라 검색창을 닫는 것이기 때문이에요.
- `replace` 이동은 기본적으로 전환하지 않아요. 권한·세션 안전장치(남의 예약·변경 불가 예약 → 내 예약, 권한 없음 → 홈, 이미 로그인됨), 소셜 로그인 콜백, 메신저 내부 주소 정리가 여기에 해당해요.
- 사용자가 끝낸 흐름은 호출부가 `reserveRouteMotion`으로 방향을 명시해요.

| 이동 | 방향 |
|---|---|
| 로그아웃·탈퇴·회원가입 완료 → 홈 | 왼쪽에서(로고 → 홈과 같은 방향) |
| 로그인 필요 페이지 → 로그인, 비밀번호 변경 → 다시 로그인 | 오른쪽에서(가던 길이 이어짐) |
| 로그인 성공 → 막혔던 페이지 / 소셜 약관 동의 → 가려던 페이지 | 오른쪽에서 |
| 스스로 로그인 → 있던 페이지, 가려던 곳이 없으면 홈 | 왼쪽에서(돌아감) |

- 같은 경로 안의 변화(필터·정렬·페이지·지역·보기 방식·패널 탭)는 전환하지 않아요. 판정은 `routeEntryMotion.js` 한 곳에서 해요.
- 들어가기와 나가기는 짝을 맞춰요. 메신저 목록 → 대화(오른쪽에서) ↔ 뒤로(오른쪽으로), 헤더 뒤로가기 나타남 ↔ 눌러서 사라짐, 광고 신청 다음 단계(오른쪽에서) ↔ 이전 단계(왼쪽에서).
