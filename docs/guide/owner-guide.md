# 사장님 가이드

RESERVE 파트너로 가게를 등록하고 예약을 관리하는 방법을 안내합니다.

---

## 파트너 가입 (사업자 인증)

1. 회원가입 후 **마이페이지** → **사업자** 탭 이동
2. 상호명 · 사업자 등록번호 입력
3. 사업자 등록증 이미지 업로드
4. **사업자 인증 신청** 클릭
5. 관리자 승인 후 파트너 권한 부여 (이메일 알림)

---

## 가게 등록

1. 상단 메뉴 → **내 가게** → **새 가게 등록**
2. 기본 정보 입력
   - 가게 이름 · 카테고리 · 주소 · 전화번호 · 소개
3. 이미지 등록
   - 대표 이미지 1장 (필수), 상세 이미지 최대 5장
   - JPG · PNG · WEBP · GIF, 새 이미지 전체 합계 최대 8MB
4. 운영 설정
   - 영업시간 · 예약 슬롯 단위
   - 슬롯당 최대 인원
   - 예약 마감 시간
5. 예약금 설정 (선택)
   - 노쇼 예약금 금액
   - 환불 정책 (전액/부분 환불 기준일)
   - 결제 대기 시간
6. 작성 중인 내용은 이 브라우저에 자동 임시저장됨
   - 회색 **임시저장** 버튼으로 즉시 저장할 수도 있음
   - 다시 들어왔을 때 임시저장 내용을 이어 쓸지 선택
7. **등록 완료** 클릭

---

## 예약 관리

1. 상단 메뉴 → **사업자 패널**
2. 들어온 예약 목록 확인
3. 예약 처리

| 버튼 | 설명 |
|---|---|
| **승인** | 예약 확정 (고객에게 이메일 발송) |
| **거절** | 예약 거절 (고객에게 이메일 발송) |
| **완료** | 방문 완료 처리 |
| **노쇼** | 고객 미방문 처리 |

> **자동 승인** 설정 시 예약 신청 즉시 자동으로 확정됩니다.

---

## QR 체크인 (방문 확인)

손님이 방문하면 예약 QR 코드로 방문을 확인할 수 있습니다.

1. **사업자 패널** → **QR 스캔** 탭 이동
2. 카메라로 손님의 예약 QR 코드를 스캔
3. 승인된 예약이면 실제 방문 시각이 기록됩니다

체크인은 예약 승인이나 이용 완료를 대신하지 않습니다. 예약은 먼저 승인되어 있어야 하며,
서비스가 끝난 뒤에는 예약 목록에서 **완료**를 별도로 눌러주세요.

> 손님은 **내 예약**에서 예약 코드(R-날짜-XXXX)와 QR 코드를 확인해 보여줍니다.

## 광고 (가게 홍보)

가게를 더 많은 손님에게 노출하고 싶다면 광고를 등록할 수 있습니다.

1. **사업자 패널** → **광고** 탭 이동
2. 광고 유형 선택
   - **노출형** — 가게 목록의 카드·리스트에서 상단 우선 노출, 작은 `광고` 표기
   - **배너형** — 가게 목록 화면 오른쪽 아래의 플로팅 배너로 노출
3. 노출 기간 선택
4. 배너형이면 추천 문구를 고른 뒤 제목·내용을 수정하고 대표 이미지와 등장 효과 선택
5. **미리보기**에서 노출형은 카드·리스트를, 배너형은 실제 크기·문구·효과를 확인하고 신청 기간·결제 예정 금액 확인
6. **결제하기**에서 카카오페이 결제 (포트원)
7. 결제 완료 후 광고 자동 게시 (기간 만료 시 자동 종료)

> 광고 노출 수 · 클릭 수는 광고 탭에서 확인할 수 있습니다.

---

## 통계

**사업자 패널** → **통계** 탭에서 가게의 예약 현황과 예약금 순결제액 추이를 확인할 수 있습니다.
순결제액은 예약 방문일이 아니라 결제 완료일 기준이며 확정된 환불액을 차감합니다. 차트 아래
**데이터 표 보기**에서 같은 수치를 표로 확인할 수 있습니다.

---

## 가게 수정

1. **내 가게** → 수정할 가게의 **수정** 버튼
2. 원하는 항목 수정 (등록 화면과 같이 이 브라우저에 자동 임시저장)
3. **수정 완료** 클릭

---

## 가게 삭제

1. **내 가게** → 삭제할 가게의 **삭제** 버튼
2. 확인창에서 영업 종료 의사를 확인
3. 미결 예약·광고·환불·결제 확인·웹훅이 하나라도 남아 있으면 서버가 **409로 차단**하므로 먼저
   해당 항목을 처리합니다. 확인창은 이 안전장치를 우회하거나 강행 삭제하지 않습니다.

---

## 알림 설정

**마이페이지** → **알림 설정**에서 예약 승인/거절 시 이메일 알림을 켜거나 끌 수 있습니다.

---

## 사업자 자격 포기

**마이페이지** → **사업자** 탭 → **포기하기**

> 포기 시 가게 관리 및 예약 수신이 불가합니다.
