# 사장님 가이드

RESERVE 파트너로 가게를 등록하고 예약을 관리하는 방법을 안내해요.

## 파트너 가입 (사업자 인증)

1. 회원가입 후 **마이페이지** → **사업자** 탭으로 이동해요.
2. 상호명과 사업자 등록번호를 입력해요.
3. 사업자 등록증 이미지를 올려요.
4. **사업자 인증 신청**을 눌러요.
5. 관리자가 승인하면 파트너 권한이 생기고 이메일로 알려 드려요.

## 가게 등록

1. 상단 메뉴 → **내 가게** → **새 가게 등록**으로 이동해요.
2. 기본 정보를 입력해요. (가게 이름 · 카테고리 · 주소 · 전화번호 · 소개)
3. 이미지를 등록해요.
   - 대표 이미지 1장(필수), 상세 이미지 최대 5장
   - JPG · PNG · WEBP · GIF, 새 이미지 전체 합계 최대 8MB
4. 운영을 설정해요.
   - 영업시간 · 예약 슬롯 단위
   - 슬롯당 최대 인원
   - 예약 마감 시간
5. 필요하면 예약금을 설정해요. (선택)
   - 노쇼 예약금 금액
   - 환불 정책 (전액/부분 환불 기준일)
   - 결제 대기 시간
6. **등록 완료**를 눌러요.

> 작성 중인 내용은 이 브라우저에 자동으로 임시저장돼요. 회색 **임시저장** 버튼으로 바로 저장할 수도 있고, 다시 들어오면 이어 쓸지 고를 수 있어요.

## 예약 관리

1. 상단 메뉴 → **사업자 패널**로 이동해요.
2. 들어온 예약 목록을 확인해요.
3. 버튼으로 예약을 처리해요.

| 버튼 | 설명 |
|---|---|
| **승인** | 예약 확정 (고객에게 이메일 발송) |
| **거절** | 예약 거절 (고객에게 이메일 발송) |
| **완료** | 방문 완료 처리 |
| **노쇼** | 고객 미방문 처리 |

> **자동 승인**을 켜면 예약 신청이 들어오는 즉시 확정돼요.

## QR 체크인 (방문 확인)

손님이 방문하면 예약 QR 코드로 방문을 확인할 수 있어요.

1. **사업자 패널** → **QR 스캔** 탭으로 이동해요.
2. 카메라로 손님의 예약 QR 코드를 스캔해요.
3. 승인된 예약이면 실제 방문 시각이 기록돼요.

체크인은 예약 승인이나 이용 완료를 대신하지 않아요. 예약은 먼저 승인돼 있어야 하고, 서비스가 끝나면 예약 목록에서 **완료**를 따로 눌러 주세요.

> 손님은 **내 예약**에서 예약 코드(R-날짜-XXXX)와 QR 코드를 확인해 보여 줘요.

## 광고 (가게 홍보)

가게를 더 많은 손님에게 보여 주고 싶다면 광고를 등록할 수 있어요.

1. **사업자 패널** → **광고** 탭으로 이동해요.
2. 광고 유형을 골라요.
   - **노출형** — 가게 목록의 카드·리스트 상단에 우선 노출되고, 작은 `광고` 표기가 붙어요.
   - **배너형** — 가게 목록 화면 오른쪽 아래에 플로팅 배너로 노출돼요.
3. 노출 기간을 골라요.
4. 배너형이면 추천 문구를 고른 뒤 제목·내용을 다듬고, 대표 이미지와 등장 효과를 골라요.
5. **미리보기**에서 노출형은 카드·리스트를, 배너형은 실제 크기·문구·효과를 확인하고, 신청 기간과 결제 예정 금액도 확인해요.
6. **결제하기**에서 카카오페이로 결제해요. (포트원)
7. 결제가 끝나면 광고가 자동으로 게시되고, 기간이 끝나면 자동으로 종료돼요.

> 광고 노출 수와 클릭 수는 광고 탭에서 볼 수 있어요.

## 통계

**사업자 패널** → **통계** 탭에서 가게의 예약 현황과 예약금 순결제액 추이를 볼 수 있어요. 순결제액은 방문일이 아니라 결제 완료일 기준이고, 확정된 환불액을 뺀 금액이에요. 차트 아래 **데이터 표 보기**에서 같은 수치를 표로 볼 수 있어요.

## 가게 수정

1. **내 가게** → 수정할 가게의 **수정** 버튼을 눌러요.
2. 원하는 항목을 고쳐요. 등록할 때처럼 이 브라우저에 자동으로 임시저장돼요.
3. **수정 완료**를 눌러요.

## 가게 삭제

1. **내 가게** → 삭제할 가게의 **삭제** 버튼을 눌러요.
2. 확인창에서 영업 종료 의사를 확인해요.

> 주의: 미결 예약·광고·환불·결제 확인·웹훅이 하나라도 남아 있으면 서버가 **409로 차단**해요. 해당 항목을 먼저 처리해 주세요. 확인창에서 이 안전장치를 건너뛰거나 강제로 삭제할 수는 없어요.

## 알림 설정

**마이페이지** → **알림 설정**에서 예약 승인/거절 이메일 알림을 켜거나 끌 수 있어요.

## 사업자 자격 포기

**마이페이지** → **사업자** 탭 → **포기하기**를 눌러요.

> 포기하면 가게 관리와 예약 수신을 할 수 없어요.
