# 가게 임시저장

가게 등록·수정의 입력과 선택 사진을 같은 브라우저에서 이어 쓸 수 있어요.

## 동작

- 입력이 잠시 멈추면 자동 저장하며 임시저장 버튼도 제공해요.
- 계정 메뉴의 임시보관함(`/drafts`)은 피드 글, 가게 등록·수정, 가게 소식·혜택을 보여줘요. 전체 화면은 종류별로 최대 3개를 표시하고, 각 메뉴에서 전체 목록을 페이지로 나눠 확인해요. 사업자 메뉴는 사업자·관리자에게 표시해요.
- 등록·수정 화면으로 직접 들어오면 저장 시각과 함께 이어서 작성할지 물어요.
- 새로 작성하거나 최종 저장에 성공하면 해당 초안을 지워요.
- 수정 중 서버의 원본이 바뀌면 차이를 확인하도록 안내해요.

## 저장 범위

가게 등록·수정 초안은 브라우저 IndexedDB에 저장하고 회원·등록/수정·가게별로 구분해요. 날짜와 새 사진도 함께 보관해요.

초안은 30일 뒤 만료돼요. 작성한 주소와 브라우저에서 이어 쓸 수 있고, 서버에는 최종 제출할 때 저장해요.

피드와 가게 소식의 초안은 기존 서버 조회로 읽고 각 작성기에서 이어 써요. 임시보관함은 저장된 초안의 제목과 저장 시각을 모아서 표시해요.

관리자 새 메일 초안은 가게 양식과 같은 IndexedDB의 별도 저장소에서 관리자별로 30일 동안 보관해요. 받는 주소·제목·본문·광고성 여부·첨부 사진을 저장하며, 메일함의 보낸 메일 목록 또는 임시보관함의 메일 초안에서 이어 써요. 발송 성공 시 연결된 초안을 삭제해요.

## 코드 위치

[storeDraftStorage.js](../../frontend/src/utils/storeDraftStorage.js)가 저장·복원을, useStoreForm과 StoreFormActions가 등록·수정 화면의 동작을 담당해요.
