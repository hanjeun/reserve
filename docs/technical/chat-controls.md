# 채팅 관리

채팅 입력, 대화 설정, 전송 취소와 신고를 관리해요.

## 입력과 사진

- 메시지 작성·사진 선택·전송을 같은 입력 영역에서 처리해요.
- 전송 중에는 중복 요청을 막고 실패하면 입력을 유지해요.
- 사진 형식과 크기는 화면과 서버에서 각각 확인해요.
- 사진 확대와 파일 읽기는 대화 참여 권한을 확인해요.

## 프로필과 안내

고객지원은 이름·원형 프로필 사진·인사말·자주 묻는 질문을 설정해요. 사진은 기존 업로드·확대·삭제 기능을 사용하고 기본 사진 복귀는 회색 밑줄 버튼으로 제공해요.

가게 문의의 이름과 사진은 가게 정보를 사용해요. 채팅 설정에서 다른 가게의 이름이나 사진으로 바꾸지 않아요.

작성한 설정은 미리보기로 확인하고 저장해요. 저장 전 변경과 실제 적용은 구분해요.

## 대화 조작

| 기능 | 의미 |
|---|---|
| 내 목록에서 숨기기 | 상대방의 대화는 유지 |
| 전송 취소 | 허용된 조건에서 내가 보낸 내용 취소 |
| 차단 | 상대와의 전송 제한 |
| 신고 | 해당 내용과 증거를 관리자에게 전달 |

신고 증거 조회는 관리자 권한과 접근 기록을 사용해요. 분쟁·보존 요청이 있는 원문은 일반 만료 처리와 구분해요.

세부 보존 원칙은 [데이터 보관과 삭제](data-lifecycle.md), 공통 대화 구조는 [통합 메시지](messaging.md)를 보세요.
