# 손님 가이드

RESERVE에서 가게를 찾고 예약하는 방법을 안내해요.

## 회원가입

1. 우측 상단 **로그인** 버튼을 눌러요.
2. **회원가입**을 선택해요.
3. 이메일을 입력하고 **인증코드 전송**을 눌러요.
4. 이메일로 받은 인증코드를 입력해요.
5. 이름과 비밀번호를 입력하면 가입이 끝나요.

> Google, Naver, Kakao 계정으로도 바로 가입할 수 있어요.

## 가게 찾기

1. **가게 둘러보기** 버튼이나 상단 메뉴에서 가게 목록으로 이동해요.
2. 검색창에 가게 이름이나 키워드를 입력해요.
3. 정렬 기준을 골라요. (거리순 / 평점순 / 최신순 / 리뷰순)
4. 원하는 가게 카드를 눌러요.

> 위치 정보를 허용하면 **거리순** 정렬과 가까운 가게의 **우리동네** 배지를 볼 수 있어요.

## 예약하기

1. 가게 상세 페이지에서 **예약하기**를 눌러요.
2. 날짜 · 시간 · 인원을 선택해요.
3. 요청 사항이 있으면 입력해요. (선택)
4. **예약 신청** 버튼을 눌러요.

> 예약금이 있는 가게는 예약 후 결제 화면으로 이동해요.

## 예약금 결제 (카카오페이)

1. 결제 화면에서 **카카오페이로 결제**를 눌러요.
2. 카카오페이 앱에서 결제를 승인해요.
3. 결제가 끝나면 예약이 확정돼요.

> 결제하지 않으면 일정 시간 후 예약이 자동으로 취소돼요.

## 예약 확인 · 수정 · 취소

1. 우측 상단 프로필 → **내 예약 확인**으로 이동해요.
2. 예약 목록에서 상태를 확인해요. (대기중 · 확정 · 완료 · 취소)
3. **수정** — 확정 전 예약은 날짜 · 시간 · 인원을 바꿀 수 있어요.
4. **취소** — 해당 예약의 **취소** 버튼을 눌러요.

> 환불 정책은 가게마다 다를 수 있어요.

## 방문 · QR 체크인

1. **내 예약**에서 방문할 예약을 선택해요.
2. 예약 코드(R-날짜-XXXX)와 **QR 코드**를 확인해요.
3. 승인된 예약의 QR을 방문할 때 사장님에게 보여 주면 체크인 시각이 기록돼요.

## 리뷰 작성

1. 완료된 예약의 **리뷰 작성** 버튼을 눌러요.
2. 별점과 내용을 입력하고 등록해요.

## 즐겨찾기

- 가게 카드나 상세 페이지의 **하트 아이콘**을 눌러요.
- 프로필 → **즐겨찾기**에서 모아 볼 수 있어요.

## 마이페이지

프로필 → **마이페이지**에서 아래 정보를 바꿀 수 있어요.

- 이름
- 비밀번호 (이메일 회원만)
- 프로필 사진
- 예약 알림 이메일 수신 설정
- 사업자 전환 신청
