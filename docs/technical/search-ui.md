# 검색 화면

상단 검색창에서 전용 검색 화면으로 들어가 가게를 찾아요.

## 흐름

1. 검색 화면에서 검색어를 입력해요.
2. Enter나 키보드의 검색 동작으로 제출해요.
3. 가게 목록에서 결과를 확인하고 검색어·분야·정렬·페이지를 바꿀 수 있어요.

검색 실행과 분야·전체 보기 이동은 검색 입력 화면의 방문 기록을 교체해요. 결과에서 뒤로가면 검색 전 화면으로 돌아가요.

## 화면 구성

- 공통 헤더 검색창과 전용 검색 입력은 높이 44px의 pill이에요.
- 검색 화면에서는 전역 헤더·푸터를 숨기고 입력에 집중해요.
- 최근 검색어는 기기의 로컬 기록이며 삭제할 수 있어요.
- 빠른 검색 문구는 안내용 예시이며 실시간 인기 순위가 아니에요.
- 검색 결과의 실제 데이터는 서버에서 조회해요.

## 조작과 모션

검색 입력에 포커스를 주고, 취소·Escape는 검색 전 화면으로 복귀해요. 검색 실행·분야 선택·취소는 같은 닫힘 동작을 사용해요.

캐시된 본문이 바로 보이면 본문에서, 페이지 골격이 먼저 보이면 골격에서 한 번만 진입해요. 골격에서 본문으로 바뀔 때는 반복하지 않아요. 모션 줄이기 설정을 따르며 새 탭 열기는 현재 화면을 닫지 않아요.
