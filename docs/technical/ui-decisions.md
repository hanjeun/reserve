# 공통 UI 규칙

화면마다 새 컨트롤을 만들기보다 같은 역할의 기존 컴포넌트를 사용해요.

## 화면 구성

- 헤더와 주요 탐색은 공통 레이아웃을 사용해요.
- 폼·관리·공개 목록은 각 화면에 맞는 폭을 유지해요.
- 공개 가게 결과와 관리 목록은 서버 페이지네이션을 사용해요.
- 목록 조건과 페이지는 주소에 보존하고, 조건 변경 시 첫 페이지로 이동해요.

## 조회 상태

첫 조회에는 본문과 맞는 골격을 보여줘요. 다시 조회하는 동안에는 기존 목록·입력을 유지해요.

정상 0건, 일시 오류, 접근 거부, 삭제된 자료를 구분해요. 권한이 없어진 자료는 이전 내용을 계속 노출하지 않아요.

## 입력과 실행

검증은 입력 가까이 표시하고 서버의 최종 규칙을 유지해요. 저장 중에는 중복 실행을 막고 실패하면 입력을 보존해요.

사진 선택·초기화·저장은 각 화면의 기존 저장 정책을 따르며, 선택만으로 다른 데이터가 저장되지 않도록 해요.

## 공통 컴포넌트

| 역할 | 컴포넌트 |
|---|---|
| 입력·검증 | FormInput·FormSelect·FormField |
| 간단한 목록 선택 | FilterMenu |
| 작업 버튼·아이콘 | Button·IconTool |
| 사진 선택 | ProfilePhotoPicker |
| 빈 상태·오류 | DataState·PageStatus |
| 공통 모달 | FormModal·useMessage |

색·크기·모양과 모션은 [디자인 시스템](design-system.md)을 따르며, 실제 구현은 frontend/src/components/common에 있어요.
