# 지역 사진

지역 탐색에 사용하는 사진은 서버가 외부 관광 사진 API에서 조회해 제공해요.

## 흐름

1. 브라우저가 지역 사진을 요청해요.
2. 서버가 지역·캐시·제공 조건을 확인해요.
3. 같은 출처의 이미지 응답으로 사진을 전달해요.
4. 사진이 없거나 조회에 실패하면 기본 이미지를 사용해요.

## 설정과 권리

- 외부 API 키는 서버에만 두어요.
- 제공자의 사용 조건과 필요한 출처 정보를 유지해요.
- 실제 응답에 없는 지역·사진·적중률을 만들어 표시하지 않아요.
- 사진의 사용 조건이 맞지 않으면 제공하지 않아요.

서비스의 콘텐츠 출처 안내와 [서드파티 고지](../../THIRD_PARTY_NOTICES.md)를 함께 제공해요.

## 코드 위치

backend의 tourism 영역과 프론트의 지역 탐색 컴포넌트에서 조회·캐시·기본 이미지 처리를 나눠요.
