# 디자인 시스템

공통 토큰과 컴포넌트를 사용해 화면의 색·크기·상호작용을 유지해요.

## 토큰과 스타일

| 위치 | 역할 |
|---|---|
| frontend/src/styles/tokens | 색·글자·간격·모서리·모션 값 |
| frontend/src/styles/theme.css | 테마 CSS 변수 |
| frontend/src/styles/global | 공통 상태와 화면별 CSS |
| frontend/src/index.css | 전역 CSS 진입점 |

컴포넌트의 지역 배치는 인라인 스타일로, hover·focus·반응형 규칙은 기존 전역 CSS에서 관리해요.

## 모양

- 작은 텍스트 실행 버튼과 빠른 검색 칩은 pill 모양을 사용해요.
- 일반 버튼·입력·선택·카드는 각 역할의 기존 모서리를 유지해요.
- 프로필 사진과 사진 선택기는 원형이에요.
- 같은 역할의 컴포넌트를 재사용하고 서로 다른 컨트롤을 한 모양으로 바꾸지 않아요.

## 아이콘 도구

| 역할 | hover 면 |
|---|---|
| 검색·뒤로·현재 위치·사진 위 하트 | 원형 |
| 닫기·새로고침·작성·보기 전환·읽음 도구 | 둥근 네모 |

공통 기준은 클릭 영역 44px, 보이는 면 32px, 아이콘 20px예요.

명확한 검색·뒤로·닫기·보기 전환에는 툴팁을 생략하고 접근성 이름을 유지해요. 설명이 필요한 도구는 공통 Tooltip을 사용해요.

PC에서는 hover·키보드 포커스, 터치에서는 500ms 길게 누르기로 짧은 설명을 표시해요. 손을 떼거나 스크롤하면 닫고 길게 누른 동작의 클릭은 실행하지 않아요. 링크의 기본 길게 누르기와 InfoHint의 설명 고정은 구분해요.

## 텍스트 링크와 동작

푸터와 같은 중립 텍스트는 기본 보조색에서 hover·키보드 포커스·누름 상태에 진한 글자와 밑줄을 표시해요. 비활성 상태에는 이 효과를 적용하지 않아요.

이동은 TextLink, 간단한 실행은 UnderlinedTextButton을 재사용해요. Button의 중립 ghost·ghost-sm과 검색 취소·최근 검색 전체 삭제도 같은 text-links.css 규칙을 사용해요. 강조색 버튼·아이콘 도구·채움 버튼·선택 칩은 각 역할의 기존 상태와 모양을 유지해요.

## 입력과 선택

| 컴포넌트 | 용도 |
|---|---|
| FormInput·FormTextArea | 일반 텍스트 입력 |
| FormSelect | 폼 안의 값 선택 |
| FilterMenu | 목록의 분야·정렬 선택 |
| FormDatePicker·FormTimePicker | 날짜·시간 입력 |
| FormField·Form.Item | 입력 이름과 검증 오류 |

검증 오류는 해당 입력 아래에 표시하고, 값이 올바르게 바뀔 때 해제해요. 정상 0건과 조회 실패는 다른 화면으로 표현해요.

가게 상세와 결제 요약의 아이콘·보조색 라벨·값·구분선은 DetailInfoRows를 재사용해요. 결제 브랜드 표시는 원본 비율과 고유 색을 유지하고 단색 로고는 테마에 맞는 밝기로 표시해요.

## 사진과 상태

- 계정·공개프로필 사진은 ProfilePhotoPicker를 사용해요.
- 기본 사람 프로필은 공통 선 아이콘과 투명 배경을 사용하며 사진의 원형 틀을 유지해요.
- 고객지원 사진은 ProfilePhotoUpload로 원형 등록·확대·삭제를 제공해요.
- 기본 사진 복귀는 ProfilePhotoResetButton을 사용해요.
- 일반 사진 등록은 LoadingUpload·ImageUploadButton을 재사용해요.
- 빈 상태와 오류는 DataState·PageStatus를 사용해요.
- 로딩 골격은 실제 본문의 크기와 배치에 맞춰요.

## 모션

페이지는 처음 보이는 본문이나 페이지 골격에서 한 번만 진입해요. 골격이 본문으로 바뀔 때 다시 실행하지 않아요. 지도·달력 같은 부분 로딩은 페이지 진입과 구분해요.

검색과 메신저는 각 화면의 열림·닫힘 동작을 사용해요. 검색도 처음 보인 골격 또는 본문에서 한 번만 진입해요. 닫히는 요소는 모션이 끝날 때까지 유지하고 중복 조작을 막아요.

모션 줄이기 설정에서는 이동·확대 효과를 줄이거나 생략해요. 선택 상태와 키보드 포커스는 유지해요. 결제 남은 시간은 고정 문구·콜론을 유지하고 바뀌는 숫자 자리만 기존 RollingFieldValue로 전환해요. 1분 이하·만료의 색상은 전환하고 만료 문구는 공통 AnimatedContent를 사용해요.

## 접근성

동작은 네이티브 버튼, 페이지 이동은 링크로 제공해요. 키보드 조작·이름·포커스 표시를 유지하고 버튼 안에 다른 버튼이나 링크를 중첩하지 않아요.

## 화면과 조회 상태

공통 레이아웃을 사용하고 폼·관리·공개 목록의 기존 폭을 유지해요. 목록 조건과 페이지는 주소에 보존하며 조건을 바꾸면 첫 페이지로 이동해요.

첫 조회와 새 검색에는 본문과 맞는 골격을, 같은 조건의 자동 갱신에는 기존 목록을 유지해요. 정상 0건·일시 오류·접근 거부·삭제를 구분하고 권한을 잃은 자료는 숨겨요.

저장 중에는 중복 실행을 막고 실패하면 입력을 보존해요. 사진 선택만으로 다른 입력을 저장하지 않아요. 작성·제출 모달은 FormModal과 공통 액션을 사용해요.
