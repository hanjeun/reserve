# 가게 목록 보기 전환

2026-09-14 `local-preview-all-changes` 로컬 구현·검증 기록. 운영 배포나 최신 dev 통합 증거가 아니다.

## 구현

- 대상은 `/stores` 전체·분야·검색 결과다. 홈·관심 가게·내 가게에 새 보기 선택을 추가하지 않았다.
- 분야·정렬 오른쪽 끝에 `StoreListViewToggle`을 둔다. 기본은 기존 원본 비율 `StoreCard` 그리드이며, 한 번 누르면 `StoreListRow` 목록형으로 전환한다.
- 아이콘은 다음 동작을 나타낸다. 사진형에서는 목록 아이콘, 목록형에서는 격자 아이콘이다. 추가 안내 문구 없이 접근성 라벨·title을 제공한다. 44px 터치 영역·중립 키보드 포커스·Enter/Space와 테마 토큰을 유지하며 hover 배경 박스나 축소 효과는 추가하지 않는다.
- 목록형은 모든 폭에서 1열이다. 왼쪽 사진은 모바일 80×80px, 768px 이상 96×96px, 반경 14px이다. 정사각 면 안에서 `object-fit: cover`로 표시하고 정보와 12px 간격을 둔다.
- 오른쪽은 가게 이름 → 실제 한 줄 설명 → 평점(리뷰 수)·작은 종류 순서다. 긴 이름·설명·종류는 말줄임하며 빈 설명은 만들지 않는다. 이후 최신 사용자 피드백에 따라 리뷰가 없을 때도 별 아이콘·`0.0 (0)`으로 통일했다. 잘못된 API 값으로 NaN을 표시하지 않으며 정상 평점·리뷰 수는 보존한다. [후속 기록](search-results-and-rating-zero-2026-09-14.md)
- 기존 상세 링크·관심 가게 버튼·광고/우리동네 배지와 이미지 fallback을 유지한다. 관심 가게 버튼은 링크와 분리하고, 비로그인으로 버튼이 없으면 빈 영역을 숨긴다. 위치 권한을 새로 요청하지 않는다.
- 선택은 `view=list`와 `view=cards` URL로 대칭적으로 유지한다. 값이 없거나 알 수 없는 기존 링크는 사진형인 `view=cards`로 교정한다. 보기 변경은 현재 검색·분야·정렬·좌표·페이지·기타 URL 매개변수를 보존한다. 필터 변경의 기존 첫 페이지 복귀와 12건 서버 페이지네이션은 그대로다.
- 보기 자체는 서버 검색 조건이나 query key가 아니므로 전환만으로 가게 목록을 다시 요청하지 않는다. localStorage·사용자 계정 설정·DB에 새 선호값을 저장하지 않으며 새로 연 `/stores`의 기본 보기는 사진형이다.
- 초기 조회·재조회에는 선택한 보기의 12개 스켈레톤을 표시한다. 목록형 사진·정보 골격을 실제 행과 맞췄다. 공통 라우트 청크 fallback이나 다른 모든 페이지의 스켈레톤을 변경한 것은 아니다.
- 광고 노출 기록은 가게 ID별로 유지되는 `StoreListResult`에서 처리한다. 두 보기의 자식에는 `adId`를 넘기지 않아, 같은 결과를 사진형↔목록형으로 바꾸는 것만으로 노출을 중복 기록하지 않는다. 전체 광고 지표의 영속성·동시성 정책을 바꾼 것은 아니다.
