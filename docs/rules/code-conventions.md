# 코드 규칙

## 이름과 역할

| 대상 | 기준 |
|---|---|
| Java 클래스·React 컴포넌트 | PascalCase |
| 변수·함수·메서드 | camelCase |
| 상수 | UPPER_SNAKE_CASE |
| React hook | use로 시작 |
| CSS 클래스 | 기존 reserve- 이름과 해당 화면 범위 유지 |

서버는 controller·service·repository의 역할을 나눠요. 업무 규칙과 접근 권한은 서버의 공통 관문에서 확인해요.

## 요청과 데이터

요청 DTO와 응답 DTO를 사용하고 엔티티를 공개 응답으로 직접 전달하지 않아요. 목록은 서버 페이지 정보와 전체 건수를 사용하며, 프론트의 현재 페이지 행 수를 전체 건수로 대신하지 않아요.

데이터 변경의 원자성이 필요한 곳은 트랜잭션으로 묶어요. 외부 결제·파일·계정 서비스 호출은 데이터베이스 잠금과 재시도 경계를 구분해요.

## 화면

같은 역할의 공통 컴포넌트를 재사용해요. 색·크기는 디자인 토큰을 사용하고 전역 상태·반응형 CSS는 기존 전역 스타일 구조에 두어요.

입력 오류는 해당 필드에 표시하고, 사용자에게는 한국어로 안내해요. 자세한 기준은 [디자인 시스템](../technical/design-system.md)을 보세요.

## 로그와 주석

- 서버 로그는 영어, 사용자 메시지는 한국어를 사용해요.
- 비밀번호·토큰·개인정보·외부 원문 응답을 로그에 남기지 않아요.
- 주석은 코드에서 드러나지 않는 이유와 경계를 설명해요.
- 동작이 바뀌면 관련 주석과 문서를 함께 맞춰요.

파일의 줄바꿈은 .gitattributes를 따르며, 요청과 무관한 포맷 변경을 섞지 않아요.
