# 모니터링

## 구성

| 도구 | 역할 |
|---|---|
| Alloy | 서버 로그와 자원 지표 수집 |
| Loki | 로그 저장·조회 |
| Grafana | 대시보드와 알림 |
| Sentry | 앱 오류와 성능 정보 |
| UptimeRobot | 외부에서 서비스 응답 확인 |

## 관찰 항목

- API 오류와 응답시간
- CPU·메모리·디스크 등 서버 자원
- 결제 결과 확인이 필요한 건과 실패한 재시도 작업
- 백업 결과와 로그 수집 상태
- 브라우저의 콘텐츠 보안 정책(CSP) 보고

로그가 없을 때는 오류가 없었던 것인지, 수집이 멈춘 것인지 구분해요.

## 개인정보

로그에는 비밀번호·토큰·개인 대화·공급자 원문 응답을 남기지 않아요. Sentry의 개인정보 전송 제한과 Replay의 텍스트 마스킹·이미지 차단을 유지해요.

오류·성능·탐색 기록의 URL에서는 검색 매개변수와 fragment를 제거해요. Replay는 요청·응답 본문을 수집하지 않고, 검색 매개변수나 fragment가 포함된 페이지를 방문한 문서의 녹화를 전송하지 않아요. SDK의 원본 녹화 메타데이터를 직접 정제할 수 없어 적용하는 제한이며 오류·성능 수집은 계속해요.

CSP는 Report-Only로 위반을 관찰해요. 강제 차단으로 바꾸기 전에는 외부 지도 등 실제 화면에서 사용하는 기능과 호환되는지 확인해야 해요.
