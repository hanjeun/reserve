# 가게 임시저장

가게 등록·수정의 입력과 선택 사진을 같은 브라우저에서 이어 쓸 수 있어요.

## 동작

- 입력이 잠시 멈추면 자동 저장하며 임시저장 버튼도 제공해요.
- 다시 들어오면 저장 시각과 함께 이어서 작성할지 물어요.
- 새로 작성하거나 최종 저장에 성공하면 해당 초안을 지워요.
- 수정 중 서버의 원본이 바뀌면 차이를 확인하도록 안내해요.

## 저장 범위

초안은 브라우저 IndexedDB에 저장하고 회원·등록/수정·가게별로 구분해요. 날짜와 새 사진도 함께 보관해요.

초안은 30일 뒤 만료돼요. 일반적인 초안은 다른 기기·브라우저에서 이어지지 않으며, 서버에는 최종 제출할 때 저장해요. 앱 주소 이전용 초안 가져오기도 원래 회원과 만료 조건을 확인해요.

## 코드 위치

[storeDraftStorage.js](../../frontend/src/utils/storeDraftStorage.js)가 저장·복원을, useStoreForm과 StoreFormActions가 등록·수정 화면의 동작을 담당해요.
