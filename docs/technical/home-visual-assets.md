# 홈 이미지

홈의 분야 아이콘과 배너는 RESERVE용으로 제작한 이미지예요. 실제 입점 가게·상품·행사의 사진이라고 표시하지 않아요.

## 사용

| 종류 | 표시 방식 |
|---|---|
| 분야·바로가기 아이콘 | 배경 없는 투명 WebP |
| 모바일·태블릿 배너 | 3:2 사진 |
| PC 배너 | 2.5:1 가로 사진 |
| 운영 안내 배너 | 안내 문구와 연결한 전용 사진 |

사진에 문구를 합성하지 않고 화면의 HTML 텍스트로 제목과 설명을 제공해요.

## 배치

모바일은 분야 바로가기를 5열로, PC는 서비스와 빠른 메뉴 영역으로 나눠요. 가게 추천은 사진과 설명이 나란한 행을 사용하고 일반 가게 카드의 원본 이미지 비율과 구분해요.

배너는 직접 넘기거나 스와이프할 수 있어요. 모션 줄이기 설정을 지원해요.

## 파일 위치

- 배포 이미지: frontend/public/images/discovery-v3
- 분야 아이콘 크기: frontend/src/constants/discovery.js
- 홈 배치와 바로가기: frontend/src/pages/Home
