# 광고 결제

광고 결제는 예약금과 별도 기록으로 관리해요.

## 흐름

1. 광고 종류·노출 기간으로 금액을 계산해요.
2. 결제 시도와 주문번호를 만들어요.
3. 결제사가 확인한 금액·상태를 광고 결제 기록에 반영해요.
4. 결제와 광고 심사·노출 조건을 함께 확인해요.

## 안전장치

- 결제 시도와 환불 기록을 남겨 중복 요청을 구분해요.
- 웹훅과 수동 재조회는 같은 결제 확인 규칙을 사용해요.
- 환불 완료 뒤 도착한 오래된 결제 알림이 광고를 다시 활성화하지 않도록 해요.
- 불명확한 취소 결과는 재확인할 대상으로 남기고 두 번째 환불을 임의 실행하지 않아요.
- 광고를 지우거나 숨기는 동작과 금융 기록을 지우는 동작은 구분해요.

## 코드 위치

backend의 advertisement 영역에서 광고 주문·결제·환불을 처리해요. 결제사의 결과를 확인하는 기본 원칙은 [예약금과 환불](payments.md), 기록 보존은 [데이터 보관과 삭제](data-lifecycle.md)를 보세요.
