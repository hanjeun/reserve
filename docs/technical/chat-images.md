# 채팅 사진

채팅 사진은 공개 이미지와 달리 암호화해 보관하고, 읽을 때 대화 참여 권한을 확인해요.

## 저장과 조회

1. 서버가 파일의 실제 형식과 크기를 확인해요.
2. 사진을 AES-256-GCM으로 암호화해 저장해요.
3. 참여자가 사진을 요청하면 권한을 다시 확인하고 복호화해 제공해요.

사진은 공개 CDN으로 제공하지 않아요. 응답은 no-store를 사용하고 내게 숨긴 메시지·취소된 메시지의 접근 조건도 확인해요.

## 필수 설정

CHAT_IMAGE_ENCRYPTION_KEY는 32바이트 난수를 표준 Base64로 인코딩한 서버 전용 키예요. 브라우저 환경 변수나 저장소에 넣지 않아요.

키를 잃으면 기존 사진을 복호화할 수 없어요. 암호문과 대응 키를 함께 복구할 수 있도록 관리하며, 기존 사진이 있는 동안 임의로 키를 교체하지 않아요.

## 삭제

사진 원본의 보존기간과 신고 증거를 먼저 확인해요. 삭제 조건을 만족한 파일만 저장된 삭제 작업을 통해 정리해요.

대화 구조는 [통합 메시지](messaging.md), 보존은 [데이터 보관과 삭제](data-lifecycle.md), 복구는 [백업과 복구](backup.md)를 보세요.
